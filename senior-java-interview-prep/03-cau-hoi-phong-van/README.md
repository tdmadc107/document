## Cách luyện hiệu quả

1. **Không mở đáp án ngay.** Đọc câu hỏi, rồi tự trả lời thành tiếng (ghi âm nếu được) theo khung *định nghĩa → cơ chế → trade-off → ví dụ thực tế*.
2. Mở đáp án và so sánh với mình. Câu nào thiếu ý thì ghi lại thành flashcard và mở link **📖 Ôn lại** để đọc lại phần lý thuyết.
3. Luyện **Câu hỏi nối tiếp**. Interviewer Senior gần như luôn hỏi xoáy thêm 2–3 tầng sau câu đầu tiên.
4. Tuần 12 trong [kế hoạch ôn tập](../02-ke-hoach-on-tap.md): bốc ngẫu nhiên 40 câu trộn từ mọi module để mô phỏng phỏng vấn thật.
